# Generative AI Usage Record

Generative AI was used as a development assistant for this project.

## Areas where AI assisted

- Helped break the assignment requirements into implementation steps.
- Assisted with Java concurrency structure for the Generator, Scheduler, Ready Queue, multiple Workers, ResourceManager/Semaphore, Statistics, Monitor, and shutdown coordination.
- Assisted with reviewing synchronization and interrupt-handling logic.
- Assisted with generating test commands and organizing the required seven experiments.
- Assisted with interpreting raw logs and preparing the results table and required analysis questions.
- Assisted with documentation/README drafting.

## Verification responsibility

The project members are responsible for the submitted code and results. The implementation was compiled and executed against the provided workloads, and the generated logs were reviewed. The team must understand, explain, modify, and test the submitted code during the project demo, including thread roles, shared state protection, scheduling/tie-break behavior, semaphore acquisition/release, metrics, and graceful shutdown.

AI assistance does not replace testing or understanding of the implementation.
